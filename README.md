# ⚙️ Installation Guide

## Clone Repository

```bash
git clone https://github.com/dhanujvardhan/smart-ai-traffic-system.git
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Backend Setup

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
